Quasi-Threshold Graph
=====================

A **quasi-threshold graph** is an alternative name for a trivially perfect graph.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - ``QuasiThresholdAlgorithm``
     - Description
   * - **``DFS``** **(default)**
     - DFS-based recognition
