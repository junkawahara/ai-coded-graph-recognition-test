Planar Graph

A graph is planar if it can be drawn in the plane without edge crossings. By Wagner’s theorem, a graph is planar if and only if it contains no K5 or K3,3 minor. (Kuratowski’s theorem gives the equivalent characterization in terms of subdivisions rather than minors.)

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

PlanarAlgorithm

Description

LEFT_RIGHT (default)

Edge bound precheck (3n - 6), then the left-right planarity criterion of de Fraysseix, Ossona de Mendez and Rosenstiehl (two DFS passes with a stack of conflict pairs). Runs in O(n + m).

MINOR_CHECK

Edge bound precheck (3n - 6), then backtracking search for K5 and K3,3 minors. Exact but exponential in the worst case; kept as a cross-check for small graphs.

inline PlanarLabeledEnumerationResult graph_recognition::enumerate_planar_labeled_graphs_reverse_search(int n, PlanarLabeledEnumAlgorithm algo = PlanarLabeledEnumAlgorithm::REVERSE_SEARCH)

Enumerates all labeled planar graphs on vertex set {1, …, n}.

Uses reverse search. parent(G) is obtained by removing the vertex with the largest label from G. Since planar is a hereditary class, the property is preserved under removal of any vertex.

Parameters:

  • n – Number of vertices

  • algo – Algorithm selection (currently only REVERSE_SEARCH)

Returns:

PlanarLabeledEnumerationResult

The enumerator above emits labeled graphs. A second one emits a single representative per isomorphism class, by McKay’s canonical construction path method — the same scheme as the chordal and split enumerators. Graphs are grown one vertex at a time, which is sound because planar graphs are hereditary. The pruning is a check_planar call (the linear-time left-right planarity test) on every candidate child; it runs before the isomorph rejection, so the more expensive canonicalization only ever sees planar graphs. The counts are OEIS A005470(n) (1, 2, 4, 11, 33, 142, 822, 6966, 79853, …), or the connected ones among them (A003094: 1, 1, 2, 6, 20, 99, 646, 5974, …) with connected_only set.

inline PlanarUnlabeledEnumerationResult graph_recognition::enumerate_planar_unlabeled_graphs(int n, bool connected_only = false, PlanarUnlabeledEnumAlgorithm algo = PlanarUnlabeledEnumAlgorithm::CANONICAL_AUGMENTATION)

Enumerates all non-isomorphic planar graphs on n vertices.

Emits one representative per isomorphism class: A005470(n) graphs (1, 2, 4, 11, 33, 142, 822, 6966, … for n = 1, 2, …), or the connected ones among them (A003094: 1, 1, 2, 6, 20, 99, 646, 5974, …) with connected_only. n = 0 yields the single empty graph in both modes; negative n and n >= 64 yield nothing.

Note

Every candidate child costs one linear-time planarity recognition plus, when it is planar, one exact canonicalization (branch and bound over vertex orderings, worst case k! on vertex-transitive graphs), so the enumeration is practical to about n = 8.

Parameters:

  • n – Number of vertices (must be < 64; see the note on practical range)

  • connected_only – If true, emit only connected graphs

  • algo – Algorithm to use (default: CANONICAL_AUGMENTATION)

Returns:

PlanarUnlabeledEnumerationResult

OEIS Count Check

For n = 1, 2, 3, 4, 5, the number of enumerated labeled planar graphs was verified to match OEIS A066537: 1, 2, 8, 64, 1023.

The non-isomorphic enumeration was verified through n = 9 against OEIS A005470 (1, 2, 4, 11, 33, 142, 822, 6966, 79853), and through n = 8 independently of the enumerator itself: the same counts come out of generating all unlabeled graphs on n vertices and filtering them by check_planar. With connected_only the counts match OEIS A003094 (1, 1, 2, 6, 20, 99, 646, 5974). The static test cases stop at n = 8.

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "planar.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_planar(g);

    std::cout << std::boolalpha << result.is_planar << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "planar_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_planar_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}

Non-isomorphic enumeration example

#include <iostream>
#include "planar_unlabeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_planar_unlabeled_graphs(6);
    std::cout << result.graphs.size() << '\n';  // 142 = A005470(6)
    return 0;
}
