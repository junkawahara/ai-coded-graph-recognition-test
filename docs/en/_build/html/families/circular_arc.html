Circular-Arc Graph

Determines whether a graph is a circular-arc graph. Each vertex corresponds to an arc on a circle, with edges between overlapping arcs.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

CircularArcAlgorithm

Description

MCCONNELL (default)

Enumerates the maximal cliques and builds a circular clique ordering. Polynomial on Helly circular-arc inputs, but falls back to exponential backtracking over clique orderings in the non-Helly case.

BACKTRACKING

Searches for an endpoint ordering on the circle via backtracking, with 2-SAT pruning. Exponential time; intended for small graphs.
enum class graph_recognition::CircularArcAlgorithm

Algorithm selection for circular-arc graph recognition.

Values:

enumerator MCCONNELL

maximal clique enumeration + circular clique ordering (default)

enumerator BACKTRACKING

backtracking + 2-SAT pruning

struct CircularArcResult

Result of circular-arc graph recognition.

Public Members

bool is_circular_arc = false

true if the graph is a circular-arc graph

std::vector<std::pair<int, int>> arcs

arcs[v] = (start, end): the arc of vertex v on a circle of 2n slots

The arc covers the slots start, start+1, …, end-1 read clockwise modulo 2n, so start > end simply means the arc wraps around. Two vertices are adjacent exactly when their slot sets meet.

Populated only by the BACKTRACKING variant, which constructs a model; MCCONNELL decides without building one and leaves this empty. Valid only when is_circular_arc == true.

The BACKTRACKING variant constructs the arc model itself and returns it (arcs[v] = (start, end) covers slots start .. end-1 clockwise on a circle of 2n slots, so start > end simply means the arc wraps around). The model is checked against the graph before it is returned. MCCONNELL decides without building a model, so arcs stays empty there.

inline CircularArcLabeledEnumerationResult graph_recognition::enumerate_circular_arc_labeled_graphs_reverse_search(int n, CircularArcLabeledEnumAlgorithm algo = CircularArcLabeledEnumAlgorithm::REVERSE_SEARCH)

Enumerates all labeled circular-arc graphs on vertex set {1, …, n}.

Uses reverse search. parent(G) is obtained by removing the vertex with the largest label from G. Circular-arc graphs are a hereditary class, so the property is preserved under any vertex removal.

Parameters:

  • n – Number of vertices

  • algo – Algorithm selection (currently only REVERSE_SEARCH)

Returns:

CircularArcLabeledEnumerationResult

Examples

Recognition example

#include <iostream>
#include "util/graph.h"
#include "recognizers/circular_arc.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_circular_arc(g);

    std::cout << std::boolalpha << result.is_circular_arc << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "enumerators/circular_arc_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_circular_arc_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}
