Bipartite Permutation Graph

Determines whether a graph is a bipartite permutation graph. A graph that is both bipartite and a permutation graph.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

BipartitePermutationAlgorithm

Description

BIPARTITE_AND_PERMUTATION (default)

Runs the bipartite recognizer and then the generic permutation graph recognizer, accepting only if both succeed. No chain structure or strong ordering is computed.
enum class graph_recognition::BipartitePermutationAlgorithm

Algorithm selection for bipartite permutation graph recognition.

Values:

enumerator BIPARTITE_AND_PERMUTATION

bipartiteness test combined with the generic permutation graph test

struct BipartitePermutationResult

Result of bipartite permutation graph recognition.

Public Members

bool is_bipartite_permutation = false

true if the graph is a bipartite permutation graph

inline BipartitePermutationResult graph_recognition::check_bipartite_permutation(const Graph &g, BipartitePermutationAlgorithm algo = BipartitePermutationAlgorithm::BIPARTITE_AND_PERMUTATION)

Determines whether a graph is a bipartite permutation graph.

G is a bipartite permutation graph iff G is bipartite and a permutation graph.

Parameters:

  • g – Input graph

  • algo – Algorithm selector (currently only BIPARTITE_AND_PERMUTATION is implemented)

Returns:

BipartitePermutationResult

Enumeration

enum class graph_recognition::BipartitePermutationLabeledEnumAlgorithm

Algorithm selection for bipartite permutation enumeration.

Values:

enumerator REVERSE_SEARCH

reverse search

struct BipartitePermutationLabeledEnumerationResult

Result of bipartite permutation enumeration.

Public Members

std::vector<EnumeratedGraph> graphs

array of enumerated bipartite permutation graphs

inline BipartitePermutationLabeledEnumerationResult graph_recognition::enumerate_bipartite_permutation_labeled_graphs_reverse_search(int n, BipartitePermutationLabeledEnumAlgorithm algo = BipartitePermutationLabeledEnumAlgorithm::REVERSE_SEARCH)

Enumerates all labeled bipartite permutation graphs on vertex set {1, …, n}.

Uses reverse search. parent(G) is obtained by removing the vertex with the largest label from G. Bipartite permutation is a hereditary class, so the property is preserved under any vertex removal.

Parameters:

  • n – Number of vertices

  • algo – Algorithm selection (currently only REVERSE_SEARCH)

Returns:

BipartitePermutationLabeledEnumerationResult

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "bipartite_permutation.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_bipartite_permutation(g);

    std::cout << std::boolalpha << result.is_bipartite_permutation << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "bipartite_permutation_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_bipartite_permutation_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}
