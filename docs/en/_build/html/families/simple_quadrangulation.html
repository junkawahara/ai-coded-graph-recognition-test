Simple Quadrangulation

A simple quadrangulation is a 3-connected planar graph where every face (including the outer face) is a quadrilateral (4-cycle). The smallest one is the cube (n = 8); C4 and K_{2,3} are only 2-connected and are rejected.

inline SimpleQuadrangulationResult graph_recognition::check_simple_quadrangulation(const Graph &g, SimpleQuadrangulationAlgorithm algo = SimpleQuadrangulationAlgorithm::COMBINED)

Determines whether the graph is a simple quadrangulation.

Simple quadrangulation <=> 3-connected planar graph with all faces being quadrilaterals. Determination: 3-connected AND planar AND m = 2n - 4 AND triangle-free.

Parameters:

  • algo – Algorithm to use (default: COMBINED)

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "simple_quadrangulation.h"

int main() {
    using namespace graph_recognition;

    // Cube graph Q_3 (8 vertices, 12 edges)
    Graph g(8, {
        {1, 2}, {2, 3}, {3, 4}, {4, 1},
        {5, 6}, {6, 7}, {7, 8}, {8, 5},
        {1, 5}, {2, 6}, {3, 7}, {4, 8}
    });
    auto result = check_simple_quadrangulation(g);

    std::cout << std::boolalpha << result.is_simple_quadrangulation << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "simple_quadrangulation_unlabeled_enum.h"

int main() {
    using namespace graph_recognition;

    // The smallest simple quadrangulation is the cube graph (n = 8),
    // so this prints 1.
    auto result = enumerate_simple_quadrangulation_unlabeled_graphs(8);
    std::cout << result.graphs.size() << '\n';
    return 0;
}
