Distance-Hereditary Graph

A graph is distance-hereditary if, in every connected induced subgraph, the distances between vertices are preserved from the original graph.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

DistanceHereditaryAlgorithm

Description

HASHMAP_TWINS

Iterative pendant/twin vertex removal using hash-map twin detection.

SORTED_TWINS

Iterative pendant/twin vertex removal using sorted neighbor-list comparison. Deterministic.

HASH_TWINS (default)

XOR hash incremental twin detection. Each vertex receives a random 64-bit weight; upon removal the neighbor hashes are updated in O(1). Hash matches are verified by exact neighbor-list comparison. Candidate buckets are rescanned after each removal, so the worst case is O(n3) on dense graphs.

SPLIT_DECOMPOSITION

Checks that every bag of Cunningham’s split decomposition is degenerate (Bandelt & Mulder 1986; see split_decomposition.h in Utilities). Slow, but it shares nothing with the three twin-elimination variants, which makes it a genuinely independent check.
enum class graph_recognition::DistanceHereditaryAlgorithm

Algorithm selection for distance-hereditary graph recognition.

Values:

enumerator HASHMAP_TWINS

Twin detection using hash map.

enumerator SORTED_TWINS

Twin detection by sorted neighbor list comparison.

enumerator HASH_TWINS

Incremental twin detection via XOR hash + exact verification (candidate buckets are rescanned per removal; worst case O(n^3) on dense graphs) (default)

enumerator SPLIT_DECOMPOSITION

every bag of the split decomposition is degenerate

Pruning sequence construction

Distance-hereditary graphs are exactly the graphs that can be reduced to a single vertex by repeatedly deleting a pendant vertex or one of a pair of twins (Bandelt & Mulder 1986). build_pruning_sequence() constructs such a sequence and names the witness of every step; it is replayed against the graph before being returned.

check_distance_hereditary() does not build the sequence, so recognition costs the same as before: recording the witnesses is more work than the fast recognizers pay to answer the question.

inline PruningSequenceResult graph_recognition::build_pruning_sequence(const Graph &g)

Builds a pruning sequence of a distance-hereditary graph.

Distance-hereditary graphs are exactly the graphs that can be reduced to a single vertex by repeatedly deleting a pendant vertex or one of a pair of twins (Bandelt & Mulder 1986). This builds such a sequence and names the witness of every step. Runs in O(n^3): each step compares the live neighbourhoods of all remaining pairs.

The sequence is replayed against the graph before being returned.

g – Input graph

inline DistanceHereditaryLabeledEnumerationResult graph_recognition::enumerate_distance_hereditary_labeled_graphs_reverse_search(int n, DistanceHereditaryLabeledEnumAlgorithm algo = DistanceHereditaryLabeledEnumAlgorithm::REVERSE_SEARCH)

Enumerates all labeled distance-hereditary graphs on vertex set {1, …, n}.

Uses reverse search. parent(G) is obtained by removing the vertex with the largest label from G. Since distance-hereditary is a hereditary class, the property is preserved under any vertex removal.

Parameters:

  • n – Number of vertices

  • algo – Algorithm selection (currently only REVERSE_SEARCH)

Returns:

DistanceHereditaryLabeledEnumerationResult

The enumerator above emits labeled graphs. A second one emits a single representative per isomorphism class, from the one-vertex extensions of Bandelt & Mulder (1986): adding a pendant vertex, a true twin, or a false twin. The connected members on k vertices are exactly the extensions of the connected members on k - 1 vertices, so the search grows level by level from K1 and rejects isomorphs by a canonical-form set per level. No recognizer is called anywhere, and a graph has 3(k - 1) children instead of the 2k-1 neighborhoods the labeled reverse search tests. Disconnected members are composed from the connected ones – the class is closed under disjoint union – as multisets of components over the integer partitions of n. The counts are OEIS A277862(n) (1, 1, 2, 6, 18, 73, 308, 1484, 7492, …) with connected_only set, or its Euler transform (1, 2, 4, 11, 31, 114, 454, 2078, 10168, …) without it.

inline DistanceHereditaryUnlabeledEnumerationResult graph_recognition::enumerate_distance_hereditary_unlabeled_graphs(int n, bool connected_only = false, DistanceHereditaryUnlabeledEnumAlgorithm algo = DistanceHereditaryUnlabeledEnumAlgorithm::VERTEX_INCREMENTAL)

Enumerates all non-isomorphic distance-hereditary graphs on n vertices.

Emits one representative per isomorphism class: A277862(n) graphs (1, 1, 2, 6, 18, 73, 308, 1484, 7492, … for n = 1, 2, …) with connected_only, and the Euler transform of that sequence (1, 2, 4, 11, 31, 114, 454, 2078, 10168, …) without it. n = 0 yields the single empty graph in both modes; negative n and n >= 64 yield nothing.

Note

The extensions themselves are cheap, but the isomorph rejection uses the shared canonicalization, an exact branch-and-bound over vertex orderings whose worst case is k! on highly symmetric graphs (this class contains K_k and K_{1,k-1}); that bounds the enumeration to about n = 9 (n = 8 takes about a third of a second, n = 9 about ten seconds, n = 10 several minutes).

Parameters:

  • n – Number of vertices (must be < 64; see the note on practical range)

  • connected_only – If true, emit only connected graphs

  • algo – Algorithm to use (default: VERTEX_INCREMENTAL)

Returns:

DistanceHereditaryUnlabeledEnumerationResult

OEIS Count Check

With connected_only, the non-isomorphic enumeration was verified through n = 9 against OEIS A277862: 1, 1, 2, 6, 18, 73, 308, 1484, 7492. The counts including disconnected members, 1, 2, 4, 11, 31, 114, 454, 2078, 10168, were checked through n = 7 against the set of isomorphism classes obtained by canonicalizing the labeled enumerator’s output.

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "distance_hereditary.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_distance_hereditary(g);

    std::cout << std::boolalpha << result.is_distance_hereditary << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "distance_hereditary_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_distance_hereditary_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}

Non-isomorphic enumeration example

#include <iostream>
#include "distance_hereditary_unlabeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_distance_hereditary_unlabeled_graphs(5);
    std::cout << result.graphs.size() << '\n';  // 31
    return 0;
}
