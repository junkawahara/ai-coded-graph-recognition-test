5-Leaf Power Graph

Determines whether a graph is a 5-leaf power.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

Recognition first checks strong chordality, then searches for a 3-Steiner root of the critical-clique quotient graph. This search is exponential in the worst case, so it runs under a step budget and throws std::runtime_error when the budget is exhausted, rather than running forever or silently answering NO.

inline FiveLeafPowerResult graph_recognition::check_five_leaf_power(const Graph &g, unsigned long long search_budget = five_leaf_power_default_budget)

Determines whether the graph is a 5-leaf power.

Parameters:

  • g – Input graph

  • search_budget – Step budget for the exponential 3-Steiner root search (0 = unlimited). Default: five_leaf_power_default_budget.

Throws:

std::runtime_error – if the budget (or the per-component memory guard) is exhausted before the search decides &#8212; the result is then unknown, never silently reported as NO

Returns:

FiveLeafPowerResult

inline FiveLeafPowerLabeledEnumerationResult graph_recognition::enumerate_five_leaf_power_labeled_graphs_reverse_search(int n)

Enumerates all labeled 5-leaf power graphs on vertex set {1, …, n}.

Extends chordal reverse search with 5-leaf power pruning. parent(G) is obtained by removing the simplicial vertex with the largest label from G.

Parameters:

n – Number of vertices

Returns:

FiveLeafPowerLabeledEnumerationResult

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "five_leaf_power.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_five_leaf_power(g);

    std::cout << std::boolalpha << result.is_five_leaf_power << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "five_leaf_power_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_five_leaf_power_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}
