Co-Chain Graph

Determines whether a graph is a co-chain graph. A graph whose complement is a chain graph.

Recognition

CochainAlgorithm

Description

COMPLEMENT

Builds the complement and applies chain graph recognition. Complexity: O(n^2).

DIRECT (default)

Complement BFS (linked-list technique) for co-bipartite detection, then verifies the suffix property. Complexity: O(n^2).
enum class graph_recognition::CochainAlgorithm

Algorithm selection for cochain graph recognition.

Values:

enumerator COMPLEMENT

chain test on the complement graph O(n^2)

enumerator DIRECT

direct test avoiding complement construction O(n^2) (default)

struct CochainResult

Result of cochain graph recognition.

Public Members

bool is_cochain = false

true if the graph is a cochain graph

std::vector<int> color

color[v] in {0, 1}: the two cliques (size n+1)

std::vector<int> x_ordering

Vertices of color 0, ordered so that the non-neighbourhood grows by inclusion.

Valid only when is_cochain == true.

std::vector<int> y_ordering

Vertices of color 1, ordered so that the non-neighbourhood grows by inclusion.

Valid only when is_cochain == true.

Obstruction obstruction

NO certificate of the complement: an ODD_CYCLE or a TWO_K2, with in_complement set.

Cochain graphs are the complements of chain graphs, so the witness is chain’s, read in the complement. The DIRECT variant avoids building the complement to decide, but builds it to produce this &#8212; the same O(n^2) the variant already costs. Valid only when is_cochain == false.

CochainResult reports the partition into the two cliques (color) and the orders in which the non-neighbourhoods grow by inclusion (x_ordering / y_ordering) – the chain structure of the complement. The DIRECT variant obtains them without building the complement.

inline CochainResult graph_recognition::check_cochain(const Graph &g, CochainAlgorithm algo = CochainAlgorithm::DIRECT)

Determines whether a graph is a cochain graph.

G is a cochain graph iff complement(G) is a chain graph.

Parameters:

  • g – Input graph

  • algo – Algorithm to use (default: DIRECT)

Returns:

CochainResult

inline CochainUnlabeledEnumerationResult graph_recognition::enumerate_cochain_unlabeled_graphs(int n)

Enumerates all non-isomorphic cochain graphs on n vertices.

Enumerates chain graphs and outputs the complement of each.

Parameters:

n – Number of vertices

Returns:

CochainUnlabeledEnumerationResult

OEIS Count Check

For n = 1, 2, 3, 4, 5, 6, the number of enumerated non-isomorphic co-chain graphs was verified, via the complement bijection with chain graphs, to match OEIS A005418: 1, 2, 3, 6, 10, 20.

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "cochain.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_cochain(g);

    std::cout << std::boolalpha << result.is_cochain << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "cochain_unlabeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_cochain_unlabeled_graphs(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}
