Halin Graph

A Halin graph is a planar graph formed by embedding a tree with no degree-2 vertices in the plane, then connecting all leaf vertices with a cycle.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

enum class graph_recognition::HalinAlgorithm

Algorithm selection for Halin graph recognition.

Values:

enumerator FACE_CHECK

Face check on planar embedding.

struct HalinResult

Result of Halin graph recognition.

Public Members

bool is_halin = false

true if the graph is a Halin graph

inline HalinResult graph_recognition::check_halin(const Graph &g, HalinAlgorithm algo = HalinAlgorithm::FACE_CHECK)

Determines whether the graph is a Halin graph.

Halin graph iff 3-connected planar graph where for some face F, removing F’s edges yields a tree T with leaf set = F’s vertex set, and all internal vertices of T have degree >= 3.

Parameters:

  • g – Input graph

  • algo – Algorithm to use (default: FACE_CHECK)

Returns:

HalinResult

Public Members

std::vector<HalinUnlabeledEnumeratedGraph> graphs
inline HalinUnlabeledEnumerationResult graph_recognition::enumerate_halin_unlabeled_graphs(int n)

Enumerates all non-isomorphic Halin graphs on n vertices.

Generates non-isomorphic trees using tree enumeration, and filters for HI-trees. Enumerates all planar embeddings of each HI-tree to construct Halin graphs, and removes duplicates using plane tree canonical codes.

Parameters:

n – Number of vertices

Returns:

HalinUnlabeledEnumerationResult

OEIS Count Check

For n = 4, 5, 6, 7, 8, 9, 10, the number of enumerated non-isomorphic Halin graphs was verified to match OEIS A346779: 1, 1, 2, 2, 4, 6, 13.

Examples

Recognition example

#include <iostream>
#include "util/graph.h"
#include "recognizers/halin.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {1, 3}, {1, 4}, {2, 3}, {2, 4}, {3, 4}});
    auto result = check_halin(g);

    std::cout << std::boolalpha << result.is_halin << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "enumerators/halin_unlabeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_halin_unlabeled_graphs(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}
