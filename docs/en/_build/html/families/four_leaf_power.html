4-Leaf Power Graph

Determines whether a graph is a 4-leaf power.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

inline FourLeafPowerLabeledEnumerationResult graph_recognition::enumerate_four_leaf_power_labeled_graphs_reverse_search(int n)

Enumerates all labeled 4-leaf power graphs on vertex set {1, …, n}.

Extends chordal reverse search with 4-leaf power pruning. parent(G) is obtained by removing the simplicial vertex with the largest label from G.

Parameters:

n – Number of vertices

Returns:

FourLeafPowerLabeledEnumerationResult

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "four_leaf_power.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_four_leaf_power(g);

    std::cout << std::boolalpha << result.is_four_leaf_power << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "four_leaf_power_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_four_leaf_power_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}
