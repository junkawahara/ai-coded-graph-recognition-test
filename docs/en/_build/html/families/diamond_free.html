Diamond-Free Graph

Determines whether a graph is diamond-free (K_4-e free). No induced subgraph isomorphic to diamond (K_4 minus one edge). Equivalently, any two triangles sharing an edge must form a K_4.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

DiamondFreeAlgorithm

Description

BRUTE

Enumerates all 4-vertex subsets to find a diamond. Complexity: O(n^4).

EDGE_PAIR (default)

For each edge, checks whether common neighbors form a clique via edge counting. The clique test scans the degrees of the common neighbors, which is O(m) per edge, so the complexity is O(m^2).
enum class graph_recognition::DiamondFreeAlgorithm

Algorithm selection for diamond-free graph recognition.

Values:

enumerator BRUTE

Enumerate all 4-vertex subsets O(n^4)

enumerator EDGE_PAIR

Check common neighbors per edge, O(m^2) total (default)

inline DiamondFreeResult graph_recognition::check_diamond_free(const Graph &g, DiamondFreeAlgorithm algo = DiamondFreeAlgorithm::EDGE_PAIR)

Determines whether the graph is diamond-free (K4-e free)

G is diamond-free iff it does not contain diamond (K4-e) as an induced subgraph. Equivalent condition: any two triangles sharing an edge form K4.

Parameters:

  • g – Input graph

  • algo – Algorithm to use (default: EDGE_PAIR)

Returns:

DiamondFreeResult

inline DiamondFreeLabeledEnumerationResult graph_recognition::enumerate_diamond_free_labeled_graphs_reverse_search(int n, DiamondFreeLabeledEnumAlgorithm algo = DiamondFreeLabeledEnumAlgorithm::REVERSE_SEARCH)

Enumerates all labeled diamond-free graphs on vertex set {1, …, n}.

Uses reverse search. parent(G) is obtained by removing the vertex with the largest label from G. Since diamond-free is a hereditary class, the property is preserved under any vertex removal.

Parameters:

  • n – Number of vertices

  • algo – Algorithm selection (currently only REVERSE_SEARCH)

Returns:

DiamondFreeLabeledEnumerationResult

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "diamond_free.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_diamond_free(g);

    std::cout << std::boolalpha << result.is_diamond_free << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "diamond_free_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_diamond_free_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}
