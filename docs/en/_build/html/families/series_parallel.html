Series-Parallel Graph

A graph is series-parallel if it contains no K4 minor. Every series-parallel graph is 2-degenerate, but the converse does not hold (e.g., a subdivision of K4 is 2-degenerate yet contains a K4 minor).

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

QUEUE_REDUCTION (default)

Queue-based series-parallel reduction.

struct SeriesParallelResult

Result of series-parallel graph recognition.

Public Members

bool is_series_parallel = false

true if the graph is a series-parallel graph

std::vector<SPReduction> reductions

The reduction steps, in the order they were applied.

Valid only when is_series_parallel == true, and then it has one entry per vertex.

SeriesParallelResult::reductions reports the reduction sequence itself (SPReduction::kind is 0 for isolated, 1 for pendant, 2 for series – the edge u-w was added – and 3 for parallel, where u-w already existed). Replaying it removes every vertex, so it can be used as a certificate.

inline SeriesParallelLabeledEnumerationResult graph_recognition::enumerate_series_parallel_labeled_graphs_reverse_search(int n, SeriesParallelLabeledEnumAlgorithm algo = SeriesParallelLabeledEnumAlgorithm::REVERSE_SEARCH)

Enumerates all labeled series-parallel graphs on vertex set {1, …, n}.

Uses reverse search. parent(G) is obtained by removing the vertex with the largest label from G. Since series-parallel is a hereditary class, the property is preserved under removal of any vertex.

Parameters:

  • n – Number of vertices

  • algo – Algorithm selection (currently only REVERSE_SEARCH)

Returns:

SeriesParallelLabeledEnumerationResult

The enumerator above emits labeled graphs. A second one emits a single representative per isomorphism class, by McKay’s canonical construction path method — the same scheme as the permutation, circle, chordal, and outerplanar enumerators. Graphs are grown one vertex at a time, which is sound because series-parallel graphs are minor-closed, hence hereditary. The pruning is a check_series_parallel call (the queue-based series/parallel reduction) on every candidate child; it runs before the isomorph rejection, so the more expensive canonicalization only ever sees series-parallel graphs. The dedicated enumerator of Kawano and Nakano generates rooted connected series-parallel graphs in constant amortized time per graph and never canonicalizes; this implementation instead reuses the shared canonical-augmentation machinery, which is practical to about n = 10. The counts are 1, 2, 4, 10, 27, 92, 360, 1715, 9356, … for n = 1, 2, …, or the connected ones among them (1, 1, 2, 5, 15, 56, 241, 1245, 7182, …) with connected_only set; neither sequence is in the OEIS as of 2026.

inline SeriesParallelUnlabeledEnumerationResult graph_recognition::enumerate_series_parallel_unlabeled_graphs(int n, bool connected_only = false, SeriesParallelUnlabeledEnumAlgorithm algo = SeriesParallelUnlabeledEnumAlgorithm::CANONICAL_AUGMENTATION)

Enumerates all non-isomorphic series-parallel graphs on n vertices.

Emits one representative per isomorphism class of K4-minor-free graphs, or the connected ones among them with connected_only. n = 0 yields the single empty graph in both modes; negative n and n >= 64 yield nothing.

Note

Every candidate child costs one series-parallel recognition (a series/parallel reduction) plus, when it passes, one exact canonicalization (branch and bound over vertex orderings, worst case k! on vertex-transitive graphs such as the cycles), so the enumeration is practical to about n = 10.

Parameters:

  • n – Number of vertices (must be < 64; see the note on practical range)

  • connected_only – If true, emit only connected graphs

  • algo – Algorithm to use (default: CANONICAL_AUGMENTATION)

Returns:

SeriesParallelUnlabeledEnumerationResult

Count Check

The non-isomorphic enumeration was verified through n = 8 independently of the enumerator itself: enumerating all unlabeled graphs by unpruned canonical augmentation and filtering them with the direct K4-minor test of util/minor.h gives the same counts (1, 2, 4, 10, 27, 92, 360, 1715; connected 1, 1, 2, 5, 15, 56, 241, 1245). Neither sequence is in the OEIS (checked 2026-08). The static test cases stop at n = 8.

Examples

Recognition example

#include <iostream>
#include "util/graph.h"
#include "recognizers/series_parallel.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_series_parallel(g);

    std::cout << std::boolalpha << result.is_series_parallel << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "enumerators/series_parallel_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_series_parallel_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}

Non-isomorphic enumeration example

#include <iostream>
#include "enumerators/series_parallel_unlabeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_series_parallel_unlabeled_graphs(6);
    std::cout << result.graphs.size() << '\n';  // 92
    return 0;
}
