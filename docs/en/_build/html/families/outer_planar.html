Outerplanar Graph

A graph is outerplanar if it can be embedded in the plane with all vertices on the outer face. Equivalently, it contains no K4 or K2,3 minor.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

OuterPlanarAlgorithm

Description

AUGMENTED_PLANARITY (default)

Tests planarity of the augmented graph G + K1 (a new vertex adjacent to all others). G is outerplanar if and only if G + K1 is planar.

MINOR_CHECK

Edge bound precheck (2n - 3), then backtracking search for K4 and K2,3 minors.

inline OuterPlanarLabeledEnumerationResult graph_recognition::enumerate_outer_planar_labeled_graphs_reverse_search(int n, OuterPlanarLabeledEnumAlgorithm algo = OuterPlanarLabeledEnumAlgorithm::REVERSE_SEARCH)

Enumerates all labeled Outerplanar graphon vertex set {1, …, n}.

Uses reverse search. parent(G) is obtained by removing the vertex with the largest label from G.outerplanar is a hereditary class, so the property is preserved under any vertex removal.

Parameters:

  • n – Number of vertices

  • algo – Algorithm selection (currently only REVERSE_SEARCH)

Returns:

OuterPlanarLabeledEnumerationResult

The enumerator above emits labeled graphs. A second one emits a single representative per isomorphism class, by McKay’s canonical construction path method — the same scheme as the permutation, circle, chordal, and interval enumerators. Graphs are grown one vertex at a time, which is sound because outerplanar graphs are hereditary. The pruning is a check_outer_planar call (the linear-time planarity test of G + K1) on every candidate child; it runs before the isomorph rejection, so the more expensive canonicalization only ever sees outerplanar graphs. The dedicated enumerator of Wang and Nagamochi generates rooted connected outerplanar graphs in constant time per graph and never canonicalizes; this implementation instead reuses the shared canonical-augmentation machinery, which is practical to about n = 10. The counts are OEIS A111564(n) (1, 2, 4, 10, 25, 80, 277, 1150, 5291, …), or the connected ones among them (A111563: 1, 1, 2, 5, 13, 46, 172, 777, 3783, …) with connected_only set.

inline OuterPlanarUnlabeledEnumerationResult graph_recognition::enumerate_outer_planar_unlabeled_graphs(int n, bool connected_only = false, OuterPlanarUnlabeledEnumAlgorithm algo = OuterPlanarUnlabeledEnumAlgorithm::CANONICAL_AUGMENTATION)

Enumerates all non-isomorphic outerplanar graphs on n vertices.

Emits one representative per isomorphism class: A111564(n) graphs (1, 2, 4, 10, 25, 80, 277, 1150, … for n = 1, 2, …), or the connected ones among them (A111563: 1, 1, 2, 5, 13, 46, 172, 777, …) with connected_only. n = 0 yields the single empty graph in both modes; negative n and n >= 64 yield nothing.

Note

Every candidate child costs one outerplanarity recognition (a linear-time planarity test of the graph plus an apex vertex) plus, when it is outerplanar, one exact canonicalization (branch and bound over vertex orderings, worst case k! on vertex-transitive graphs such as the cycles), so the enumeration is practical to about n = 10.

Parameters:

  • n – Number of vertices (must be < 64; see the note on practical range)

  • connected_only – If true, emit only connected graphs

  • algo – Algorithm to use (default: CANONICAL_AUGMENTATION)

Returns:

OuterPlanarUnlabeledEnumerationResult

OEIS Count Check

For n = 1, 2, 3, 4, 5, the number of enumerated labeled outerplanar graphs was verified to match OEIS A098000: 1, 2, 8, 63, 893.

The non-isomorphic enumeration was verified through n = 9 against OEIS A111564 (1, 2, 4, 10, 25, 80, 277, 1150, 5291), independently of the enumerator itself: the same counts come out of filtering the non-isomorphic planar enumeration by check_outer_planar. With connected_only the counts match OEIS A111563 (1, 1, 2, 5, 13, 46, 172, 777). The static test cases stop at n = 8.

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "outer_planar.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_outer_planar(g);

    std::cout << std::boolalpha << result.is_outer_planar << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "outer_planar_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_outer_planar_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}

Non-isomorphic enumeration example

#include <iostream>
#include "outer_planar_unlabeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_outer_planar_unlabeled_graphs(6);
    std::cout << result.graphs.size() << '\n';  // 80 = A111564(6)
    return 0;
}
