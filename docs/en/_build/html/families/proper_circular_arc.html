Proper Circular-Arc Graph

Determines whether a graph is a proper circular-arc graph. A circular-arc graph representable by arcs with no proper containment.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

struct ProperCircularArcResult

Result of proper circular-arc graph recognition.

Public Members

bool is_proper_circular_arc = false

true if the graph is a proper circular-arc graph

std::vector<std::pair<int, int>> arcs

arcs[v] = (start, end): the arc of vertex v on a circle of 2n slots

Same encoding as CircularArcResult::arcs, and additionally proper: no arc contains another. Valid only when is_proper_circular_arc == true.

arcs reports a proper arc model – one where no arc contains another – using the same encoding as CircularArcResult::arcs.

enumerator REVERSE_SEARCH

struct ProperCircularArcLabeledEnumerationResult

Result of proper circular-arc graph enumeration.

Public Members

std::vector<EnumeratedGraph> graphs

Array of enumerated proper circular-arc graphs.

inline ProperCircularArcLabeledEnumerationResult graph_recognition::enumerate_proper_circular_arc_labeled_graphs_reverse_search(int n, ProperCircularArcLabeledEnumAlgorithm algo = ProperCircularArcLabeledEnumAlgorithm::REVERSE_SEARCH)

Enumerates all labeled proper circular-arc graphs on vertex set {1, …, n}.

Uses reverse search. parent(G) is obtained by removing the vertex with the largest label from G. Since proper circular-arc is a hereditary class, the property is preserved under removal of any vertex.

Parameters:

  • n – Number of vertices

  • algo – Algorithm selection (currently only REVERSE_SEARCH)

Returns:

ProperCircularArcLabeledEnumerationResult

Examples

Recognition example

#include <iostream>
#include "graph.h"
#include "proper_circular_arc.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_proper_circular_arc(g);

    std::cout << std::boolalpha << result.is_proper_circular_arc << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "proper_circular_arc_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_proper_circular_arc_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}
