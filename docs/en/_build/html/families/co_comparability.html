Co-Comparability Graph

Determines whether a graph is a co-comparability graph. A graph whose complement is a comparability graph.

See ISGCI entry for this class for the definition, inclusions, and complexity of graph problems.

Recognition

CoComparabilityAlgorithm

Description

COMPLEMENT (default)

Builds the complement graph and applies comparability recognition.
enum class graph_recognition::CoComparabilityAlgorithm

Algorithm selection for co-comparability graph recognition.

Values:

enumerator COMPLEMENT

comparability test on the complement graph

struct CoComparabilityResult

Result of co-comparability graph recognition.

Public Members

bool is_co_comparability = false

true if the graph is co-comparability

Obstruction obstruction

NO certificate: a FORCING_CYCLE of the complement, with in_complement set.

Left empty by the recognizer for the same reason as comparability; build_co_comparability_obstruction() produces it. Valid only when is_co_comparability == false

inline CoComparabilityResult graph_recognition::check_co_comparability(const Graph &g, CoComparabilityAlgorithm algo = CoComparabilityAlgorithm::COMPLEMENT)

Determines whether a graph is a co-comparability graph.

G is co-comparability iff complement(G) is a comparability graph.

Parameters:

  • g – Input graph

  • algo – Algorithm selector (currently only COMPLEMENT is implemented)

Returns:

CoComparabilityResult

Enumeration

The current enumerator uses a labeled vertex-extension search. The public function name retains the historical reverse_search suffix, but the search tree is defined by the parent map that deletes the largest-labeled vertex. Starting from the empty graph, vertices 1, 2, ..., n are added in order; for each new vertex, every subset of earlier vertices is tried as its neighborhood and the candidate is filtered by check_co_comparability. Since co-comparability graphs are hereditary, every labeled co-comparability graph is reached exactly once by deleting vertices in decreasing label order.

Values:

enumerator REVERSE_SEARCH

legacy name for labeled vertex-extension search

inline CoComparabilityLabeledEnumerationResult graph_recognition::enumerate_co_comparability_labeled_graphs_reverse_search(int n, CoComparabilityLabeledEnumAlgorithm algo = CoComparabilityLabeledEnumAlgorithm::REVERSE_SEARCH)

Enumerates all labeled co-comparability graphs on vertex set {1, …, n}.

The function name keeps the historical “reverse_search” suffix. The implementation is a labeled vertex-extension search whose parent map removes the largest-labeled vertex. Co-comparability graphs are hereditary, so the property is preserved under any vertex removal.

Parameters:

  • n – Number of vertices

  • algo – Algorithm selection (currently only REVERSE_SEARCH)

Returns:

CoComparabilityLabeledEnumerationResult

The enumerator above emits labeled graphs. The other enumerator emits one representative per isomorphism class: it enumerates the non-isomorphic comparability graphs (McKay canonical construction path with check_comparability pruning) and outputs the complement of each. Complementation commutes with relabeling, so it is a bijection on isomorphism classes, and the counts equal the comparability counts, OEIS A123416.

Enumerates all non-isomorphic co-comparability graphs on n vertices.

Enumerates non-isomorphic comparability graphs and outputs the complement of each. n = 0 yields the single empty graph.

Parameters:

CoComparabilityUnlabeledEnumerationResult

OEIS Count Check

For the non-isomorphic enumeration, the counts were checked against OEIS A123416 (the comparability counts; 1, 2, 4, 11, 33, 144, 824, 6793) up to n = 8, and the output was checked to coincide with the set of isomorphism classes obtained by canonicalizing the labeled enumerator’s output up to n = 6.

Examples

Recognition example

#include <iostream>
#include "util/graph.h"
#include "recognizers/co_comparability.h"

int main() {
    using namespace graph_recognition;

    Graph g(4, {{1, 2}, {2, 3}, {3, 4}});
    auto result = check_co_comparability(g);

    std::cout << std::boolalpha << result.is_co_comparability << '\n';
    return 0;
}

Enumeration example

#include <iostream>
#include "enumerators/co_comparability_labeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_co_comparability_labeled_graphs_reverse_search(4);
    std::cout << result.graphs.size() << '\n';
    return 0;
}

Non-isomorphic enumeration example

#include <iostream>
#include "enumerators/co_comparability_unlabeled_enum.h"

int main() {
    using namespace graph_recognition;

    auto result = enumerate_co_comparability_unlabeled_graphs(6);
    std::cout << result.graphs.size() << '\n';  // 144 = A123416(6)
    return 0;
}
